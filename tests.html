Disposition Planner · Test Dashboard

Automated regression tests — run after every change to index.html

HOW TO USE: Upload both index.html and tests.html to your GitHub repo.
After any change to index.html, wait ~60 seconds for Pages to rebuild, then reload this page.
All tests should show PASS. Any FAIL means a change broke something — investigate before sharing the tool.

TO ADD A SCENARIO: Edit the SCENARIOS array at the top of the <script> in this file.
Each scenario has: name, state (patient answers), type (top/contains/not_top), expected (destination key or array of keys).
